# 대구 산단 AI 안전망 · 공장 관리자 대시보드 (시연용)

2026 대구 대학(원) AI 드래프톤 [A-05] 달구벌 프렌즈의 정책 제안 **「대구 산단 AI 안전망 구축 시범사업」**에서 공장 관리자가 보게 될 화면을 보여 주는 시연용 웹사이트입니다.

> 실제 센서·서버와 연결되어 있지 않으며, 화면의 모든 수치는 `js/data.js`에 들어 있는 **가상 데이터**입니다.

## 화면 구성

| 탭 | 내용 | 정책과의 연결 |
|---|---|---|
| 한눈에 보기 | 오늘 사용 전력, 조업 외 낭비 전력, 화재 위험 등급, 설비 이상 점수, AI가 정리한 "이번 주 할 일" | 관리자 리포트 (2장 4단계) |
| 전기 사용 | 24시간 전류와 AI(GMM)의 꺼짐·무부하·생산 판정, 평일과 휴일 비교, 낭비가 큰 설비 | ① 에너지 절약 |
| 화재 감시 | 주 차단기 R·S·T상 단자 온도, 위험 판정 방식(아크 + 온도 교차 확인), 아크 감지 기록 | ② 화재 예방 |
| 설비 상태 | 설비별 이상 점수와 3상 불평형, 8주 추이 | ③ 고장 예방 |
| 알림 | 정상·주의·위험 알림 기록, 현장 확인 결과 입력(실제 이상 / 오경보) | AI 오류 확인과 보정 |
| 월간 리포트 | 사용량, 무부하 감소율, 경보 정확도, 다음 달 할 일 (인쇄·PDF 저장 가능) | 5장 확인 지표 |

## 파일 구조

```
index.html      화면 뼈대
css/style.css   디자인
js/data.js      가상 데이터 (실제 서비스에서는 API로 대체)
js/charts.js    그래프 그리는 코드 (외부 라이브러리 없음)
js/app.js       탭 전환과 화면 동작
```

## GitHub Pages로 공개하는 방법

1. GitHub에 로그인하고 오른쪽 위 **+ → New repository**를 누릅니다.
2. Repository name에 `daegu-ai-safety-dashboard`처럼 이름을 적고, **Public**을 고른 뒤 **Create repository**를 누릅니다.
3. 새 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
4. 압축을 푼 폴더 안의 파일과 폴더(`index.html`, `README.md`, `css`, `js`)를 **그대로 끌어다 놓고** 아래 **Commit changes**를 누릅니다.
   - `css`, `js` 폴더 구조가 유지되어야 합니다. 폴더째 끌어다 놓으면 됩니다.
5. 저장소 위쪽 **Settings → 왼쪽 메뉴 Pages**로 갑니다.
6. **Build and deployment**의 Source를 **Deploy from a branch**로, Branch를 **main / (root)**로 고르고 **Save**를 누릅니다.
7. 1~2분 뒤 같은 화면 위쪽에 주소가 뜹니다.
   `https://<내 GitHub 아이디>.github.io/daegu-ai-safety-dashboard/`

## 내 컴퓨터에서 바로 보기

압축을 풀고 `index.html`을 더블클릭하면 브라우저에서 열립니다. 설치할 것은 없습니다.

## 실제 서비스로 바꿀 때

- `js/data.js`의 가상 데이터를 AI 플랫폼 API 호출로 바꿉니다.
- 관리자 로그인, 사업장별 접근 권한(관리자는 자기 사업장만, 대구시는 집계만)을 추가합니다.
- 수집 항목은 전류·온도·센서 위치로 한정합니다(영상·음성·근로자 정보 없음).
